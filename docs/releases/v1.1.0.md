# Release Notes — Local AI Harness v1.1.0

The v1.1.0 release adds the model-driven **Web Search** capability on top of the
v1.0.0 chat, SSE streaming, document context, and error-handling foundation. It does
**not** change any of that foundation: chat, streaming, cancellation, document
handling, and error envelopes are preserved.

## Highlights

- **Model-driven `web_search`.** Your model decides when to call a `web_search`
  tool, so it requires a local model and server that support OpenAI-style tool
  calling. Not every local model does — see
  [tool-call compatibility](../architecture.md#tool-call-compatibility).
- **Tavily as the first provider.** Web search starts with Tavily. The search layer
  is a pluggable provider, so more providers can be added later without changing the
  chat flow.
- **Backend-configurable Tavily endpoint.** The base URL comes from
  `AI_TAVILY_BASE_URL` (default `https://api.tavily.com`), injected into the provider
  by configuration. It is **not** hardcoded in the provider and is **not** exposed in
  the frontend UI.
- **User-configured API key.** The Tavily API key is entered in the frontend **Web
  Search settings**, stored only in the browser, and sent to the backend **only while
  web search is enabled**. It is request-scoped and never persisted or logged.
- **Basic / Advanced search depth.** `basic` is the default; `advanced` may issue more
  requests and consume more credits. Tavily bills per search — see the
  [official Tavily docs](https://docs.tavily.com/documentation/pricing).
- **Sources UI.** The answer cites the sources it used, and a **Sources** section lists
  the origin links.
- **Cancellation.** Stopping a turn halts generation, including an in-progress search.
- **Security & context limits.** Web-search results are treated as untrusted external
  data, no arbitrary result URLs are fetched, and the search path enforces HTTPS. See
  [security](../security.md).

## Configuration

| Variable | Default | Notes |
|----------|---------|-------|
| `AI_TAVILY_BASE_URL` | `https://api.tavily.com` | Backend config for the Tavily endpoint. Not exposed in the UI. |

The Tavily API key is **not** an environment variable in this release: it is entered in
the UI, not in `.env`.

## What did not change

- Chat, SSE streaming, and stop/cancel.
- Single-document context (`.txt`, `.md`, `.pdf`) and context-size configuration.
- Structured error envelope and end-to-end error handling.
- Temporary-file lifecycle and cleanup.
- Docker Compose layout and the same-origin `/api` proxy.

## Known limitations

- Web search requires a tool-capable local model/server; many small local models do not
  support tool calling.
- Only one search is allowed per user turn, with no automatic retries.
- Web content is untrusted external data and contains external links.
- Web search is not fully local: the query is sent to the configured Tavily endpoint.
